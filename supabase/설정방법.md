# 담다 로그인·서버 저장 켜는 방법 (Supabase + 카카오 + 구글)

앱 코드는 이미 들어가 있다. 아래 순서대로 계정과 설정만 만들고, 마지막에 **프로젝트 주소**와 **공개 키** 두 개를 알려 주면 코드에 넣는다.
가입·비밀번호·비밀 키 입력은 직접 해야 한다.

---

## 1. Supabase 프로젝트 만들기

1. https://supabase.com 에서 GitHub 계정으로 가입한다.
2. **New project**
   - Name: `Damda`
   - Database Password: 아무거나 길게 만들고 따로 적어 둔다 (앱에는 안 쓴다)
   - Region: **Northeast Asia (Seoul)**
   - 무료(Free) 플랜 그대로
3. 만들어지면 왼쪽 **SQL Editor** → **New query**에 `setup.sql` 내용을 통째로 붙여 넣고 **Run**.
   - `Success. No rows returned`가 나오면 끝.
   - 이 파일에 RLS(자기 기록만 읽고 쓰기)가 들어 있다. **이걸 빼먹으면 공개 키만으로 남의 메모를 볼 수 있으니 꼭 실행한다.**
4. 확인: 왼쪽 **Table Editor**에 `kv` 표가, **Storage**에 `files` 저장소(Private)가 보이면 된다.

## 2. 콜백 주소 복사

**Authentication → Sign In / Providers**에서 Kakao를 펼치면 **Callback URL**이 보인다.

```
https://<프로젝트ID>.supabase.co/auth/v1/callback
```

카카오·구글 설정에 이 주소를 넣는다.

## 3. 카카오 설정 (Kakao Developers)

1. https://developers.kakao.com → 로그인 → **내 애플리케이션 → 애플리케이션 추가하기**
   - 앱 이름 `Damda`, 회사명 `Damda`
2. **앱 키**에서 **REST API 키**를 복사해 둔다.
3. **플랫폼 → Web** 사이트 도메인에 `https://jshyunii76.github.io`를 등록한다.
4. **카카오 로그인**
   - 활성화 설정 **ON**
   - **Redirect URI**에 2번의 Callback URL을 등록한다 (틀리면 KOE006 오류).
5. **카카오 로그인 → 동의항목**
   - 닉네임: 필수 동의
   - 프로필 사진: 선택 동의
   - 카카오계정(이메일)은 비즈 앱이어야 받을 수 있어서 **설정하지 않는다**.
6. **보안 → Client Secret**: 코드 생성 → 활성화 상태 **사용함**으로 바꾸고, 코드를 복사해 둔다.

## 4. Supabase에 카카오 연결

**Authentication → Sign In / Providers → Kakao**

- Enable: ON
- REST API Key (Client ID): 3-2의 REST API 키
- Client Secret Code: 3-6의 코드
- **Allow users without an email: ON** ← 이메일을 안 받으므로 꼭 켠다
- Save

## 5. 구글 설정 (Google Cloud Console)

1. https://console.cloud.google.com → 새 프로젝트 `Damda`
2. **API 및 서비스 → OAuth 동의 화면**
   - 사용자 유형: 외부
   - 앱 이름 `Damda`, 지원 이메일 입력
   - 범위는 기본(이메일·프로필·openid)만
   - 게시 상태를 **프로덕션으로 푸시**해야 아무나 로그인할 수 있다 (테스트 상태면 등록한 사람만 됨).
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
   - 유형: 웹 애플리케이션
   - 승인된 JavaScript 원본: `https://jshyunii76.github.io`
   - 승인된 리디렉션 URI: 2번의 Callback URL
4. 나오는 **클라이언트 ID**와 **클라이언트 보안 비밀**을 복사한다.
5. Supabase **Authentication → Sign In / Providers → Google**: Enable ON, 위 두 값을 넣고 Save.

## 6. 돌아올 주소 허용

**Authentication → URL Configuration**

- Site URL: `https://jshyunii76.github.io/Damda/`
- Redirect URLs에 추가:
  - `https://jshyunii76.github.io/Damda/`
  - `http://localhost:8791/` (내 컴퓨터에서 시험할 때)

## 7. 알려 줄 것 두 개

**Project Settings → API Keys** (또는 Data API)에서:

- **Project URL**: `https://<프로젝트ID>.supabase.co`
- **공개 키**: `sb_publishable_…`로 시작하는 Publishable key, 또는 Legacy 탭의 `anon` `public` 키

이 두 개는 앱 코드에 들어가도 괜찮다 (RLS가 막아 준다).

**절대 알려 주거나 코드에 넣지 말 것**

- `sb_secret_…` Secret key, `service_role` 키
- DB 비밀번호
- 카카오 Client Secret, 구글 클라이언트 보안 비밀 (이건 Supabase 설정 화면에만 넣는다)

## 무료 플랜에서 알아 둘 것

- DB 500MB, 사진·파일 1GB, 한 달 내려받기 5GB, 월 사용자 5만 명
- **7일 동안 아무도 안 쓰면 프로젝트가 잠든다.** 대시보드에서 Restore를 누르면 다시 깨어난다.
- 사진은 앱이 줄여서 올리지만(긴 변 1400px) 가장 먼저 차는 건 파일 1GB다.

## 동작 방식 (요약)

- 로그인하면 이 기기에 있던 기록과 서버 기록을 합친다. 방·메모는 둘 다 살린다.
- 쓰는 즉시 이 기기에 저장하고, 0.7초 뒤 서버에 올린다. 인터넷이 끊기면 모아 뒀다가 연결되면 올린다.
- 앱을 다시 열 때, 그리고 켜 둔 동안 1분마다 다른 기기에서 바뀐 것을 받아 온다.
- 두 기기에서 같은 방을 동시에 고쳐도, 서로 쓴·고친·지운 메모를 합쳐서 올린다.
- 로그아웃하면 못 올린 게 없는지 확인한 뒤, 이 기기의 기록·사진·AI 키를 지운다.

## 담다 AI (키 없이 쓰기)
1. SQL Editor 에 `ai.sql` 을 붙여 넣고 Run (하루 한도: 글 60번 · 벡터 600번 / 사람)
2. Edge Functions → Deploy a new function → Via Editor → `functions/ai/index.ts` 내용, 이름 `ai`
3. Edge Functions → Secrets → `GEMINI_API_KEY` 에 Gemini 키 (https://aistudio.google.com/apikey)
   - 키가 없으면 앱은 "담다 AI가 아직 준비 중"이라고 안내하고, 학생이 자기 키를 넣으면 그 키를 쓴다
