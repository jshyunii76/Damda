## 2. 조사에서 나온 결론 [판단]

1. 정리 도구(TeamFit·노션 등)는 많다. **"대신 해 주는" 팀플 도구는 못 찾음.**
2. 피클이 놀라운 이유는 **먼저 제안 + 대신 끝냄 + 과정이 보임 + 최종 승인**. 담다는 이걸 **팀플 한 영역**에 적용한다.
3. 상호평가는 **학교가 돈을 내는 시장**(CATME)인데 기존 도구는 **설문뿐**. 담다는 평가 자체는 하지 않고(과목마다 방식이 다름) **누가 뭘 했는지 실제 기록**을 제공해 각 수업의 평가 근거로 쓰게 한다.
4. 그래서 한 문장: **"과제가 뜨는 순간부터 제출까지, 팀장이 하던 일을 AI가 대신하고, 누가 뭘 했는지는 기록이 증명한다."**

## 3. 5분 시연 시나리오 — "담다 팀장 AI"

> 등장인물: 상현(팀장 역)·우진·관우 — 시연용 가짜 계정 3개. 화면 2개(발표자 폰 미러링 + 팀원 PC).
> 표시: ✅ 이미 있음 · 🛠 만들어야 함 · 🎭 시연용 준비

| # | 장면 (시간) | 화면에서 보이는 것 | '와' 포인트 | 상태 |
|---|---|---|---|---|
| 0 | **문제 제기** (30초) | "팀장 혼자 하는 일" 목록: 과제 분석, 역할 나누기, 회의 잡기, 회의록, 독촉, 상호평가 | 공감 | 🎭 슬라이드 |
| 1 | **과제가 뜬다** (40초) | Canvas에 '팀 프로젝트 기획서' 공지 → 담다 알림: **"새 팀 과제예요. 팀플방 만들고 계획 짜 둘까요?"** → [좋아요] | **먼저 제안** (피클식) | ✅ Canvas 연결·팀플방 / 🛠 '팀 과제 감지 → 알림 카드' |
| 2 | **AI가 계획을 짠다** (60초) | 과제 설명·채점 기준을 읽고 **할 일 6개 + 중간 마감(D-7 초안, D-3 검토) + 추천 역할** 미리보기 → 팀장이 담당자만 바꾸고 [확정] → 팀원 폰에 할 일 도착 | **대신 끝냄 + 최종 승인은 사람** | 🛠 AI 킥오프(분해·역할·마감) |
| 3 | **회의 날짜** (30초) | "이번 주 셋 다 비는 시간: 목 19시" (각자 Canvas 일정 기준) → [회의 잡기] | 귀찮은 조율 제거 | 🛠 공통 빈 시간 찾기 (Canvas 일정만으로 — 한계 명시) |
| 4 | **회의실** (60초) | 캐릭터 3명이 회의실에, **AI 캐릭터 '담다'** 도 앉아 있음. 말풍선 대화 → 끝나면 담다가 **"결정 2개, 할 일 3개 정리했어요"** → 방에 회의록 + 할 일·담당자 자동 | ZEP + 클로바노트를 **할 일까지** | ✅ 회의실·출석 / 🛠 AI 회의록·할 일 배정 |
| 5 | **AI가 대신 독촉** (30초) | 마감 D-1, 미완료 관우에게 담다가 정중한 알림 / 팀장 화면엔 "관우님께 알렸어요" | 팀장이 악역 안 함 | 🛠 리마인드(앱 안 알림·방 메시지) |
| 6 | ~~기여 리포트~~ **뺌** (민감, 2026-11-27) (50초) | 제출 후 **기록 기반 리포트**: 쓴 글·자료·맡은 일 완료/전체·회의 출석 → 글로 복사해 각 수업의 평가 근거로 | **기록이 증명** | ✅ |
| 7 | **사업 모델** (30초) | 학생 무료 · 학교/교수 유료(학생당 연 과금, CATME 사례) · 학교 제휴 시 LMS 버튼 한 번 | 돈 버는 구조 | 🎭 슬라이드 |

**시연 사고 대비** 🎭: 모든 장면을 **녹화본**으로도 준비. AI 응답은 시연용 과제로 미리 한 번 돌려 결과를 확인. 회의실 음성은 시연에서 빼고 말풍선만(망 문제 위험).

## 5. 정직하게 남는 질문
- **학생들이 진짜 원하는가?** 근거 없음 → 인터뷰 필요
- **AI가 짠 계획을 믿고 쓰나?** 피클처럼 "확정은 사람"으로 신뢰 문제 완화 [판단]
- **기여 리포트를 교수가 평가 근거로 받아 줄까?** 수업마다 다름 → 교수 인터뷰 필요 [판단]
- **학교가 돈을 낼까?** CATME 사례는 있으나 국내 대학 구매 과정은 모름 🔎

## 6. 인터뷰 질문지 (10명, 15분)
1. 이번 학기 팀플은 몇 개? 팀은 어떻게 정해졌나(교수 배정/자율)?
2. 팀플에서 **가장 귀찮았던 일** 3개를 순서대로? (보기 없이 먼저 묻기)
3. 그 일을 주로 누가 했나? 본인이 팀장이었다면 몇 시간쯤 썼나?
4. 지금 팀플 소통·자료 공유는 무엇으로? (카톡·노션·드라이브…) 불편한 점은?
5. 회의 날짜 잡는 데 보통 얼마나 걸리나? 회의록은 누가 쓰나?
6. 무임승차를 겪어 봤나? 그때 어떻게 했나?
7. 상호평가가 있었나? 공정했다고 느꼈나? 무엇이 있으면 더 공정할까?
8. (시연 영상 1분 보여 주고) **AI가 할 일을 나눠 주면** 쓸 것 같나? 어디가 불안한가?
9. 이런 앱을 **교수님이 쓰라고 하면** vs **스스로 찾아서** — 어느 쪽이면 쓰겠나?
10. 이 중 하나만 된다면 뭐가 제일 좋겠나? (킥오프 / 회의록 / 독촉 / 기여 증명)
