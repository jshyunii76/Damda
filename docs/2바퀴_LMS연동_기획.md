# 2바퀴 기획 — Canvas 연결 한 번이면 과목방·마감·팀플방이 알아서

> 작성: 2026-11-25 · 1바퀴 결과: [PR #3](https://github.com/jshyunii76/Damda/pull/3) (공유방 서버 구조)
> 표기: ✅ 원문 확인 / 📁 코드 확인 / 🔎 아직 확인 못 함 / [판단] 추정

## 1. 한 줄 목표
**학생이 Canvas 캘린더 주소를 한 번 붙여 넣으면, 과목별 방이 생기고 과제·퀴즈·시험 마감이 할 일로 들어오고, 팀 과제가 보이면 팀플방을 만들자고 제안한다.**

교수님 질문("카톡 나와의 채팅을 왜 떠나?")에 대한 답: *나와의 채팅에는 LMS 마감이 저절로 들어오지 않는다. 담다는 들어온다.*

## 2. 왜 지금 이게 빈자리인가
- 학생이 찾아본 '학교 앱'들은 학교 홈페이지 공지·에타 같은 것이었고, **Canvas 마감을 자동으로 가져와 정리하는 앱은 못 찾음** (팀원 조사, 2026-11-25). [판단] 시장에 빈자리가 있다는 근거로 발표에 쓸 수 있으나, 더 넓게 조사해서 확인할 필요 있음 🔎
- Canvas는 학생에게 **개인 캘린더 피드(iCal) 주소**를 공식으로 준다. 이 주소를 구글·애플 캘린더에 구독하는 기능이다 ✅ [Canvas 학생 가이드](https://community.canvaslms.com/t5/Student-Guide/How-do-I-view-the-Calendar-iCal-feed-to-subscribe-to-an-external/ta-p/331)
  - 피드에는 모든 과목의 일정과 과제가 들어간다. 단 **To Do 항목은 빠진다** ✅ (같은 문서)
- 담다는 이미 할 일·마감(D-day)·방 구조가 있다 📁 `index.html` `dueOf()`(1410줄), `ensureRoom()`(4381줄). 피드만 받으면 재료가 다 있다.

## 3. 학생이 겪는 흐름 (시나리오)
1. 담다 설정 → **"Canvas 연결하기"** → 안내 화면: ① Canvas 앱/웹에서 캘린더 열기 ② "캘린더 피드" 누르기 ③ 주소 복사 ④ 담다에 붙여 넣기 (**30초, 비밀번호·토큰 발급 없음**)
2. 담다가 피드를 읽고 → `테크노경영학`, `회계원리`… **과목방**을 만들고 → 과제·퀴즈·시험을 **마감 있는 할 일 메모**로 넣는다
3. 이후 앱을 열 때마다 새로 받아서, **새 과제는 추가 / 마감이 바뀌면 고침 / 사라진 일정은 표시**
4. 일정 이름에 "팀", "조별", "프로젝트"가 있으면 → **"이 과제로 팀플방 만들까요?"** 카드 → 누르면 1바퀴 공유방을 만들고 코드를 보여 줌 (자동으로 만들지는 않음 — 사용자 확인 후. 피클의 '확인 없이 전화' 논란에서 배운 점 ✅ [재외동포 뉴스](https://www.koreancenter.or.kr/news/articleView.html?idxno=1439464))

## 4. 범위 (이번 바퀴에 만드는 것)
| # | 항목 | 설명 |
|---|---|---|
| L1 | 연결 화면 | 피드 주소 붙여 넣기 + 단계 안내. 주소가 `https://<학교 Canvas 도메인>/feeds/calendars/…ics` 모양인지 검사 🔎(실제 모양은 샘플로 확인) |
| L2 | 서버 대리 받기 | **브라우저에서 Canvas 피드를 직접 못 받을 가능성이 큼** — 다른 개발자가 CORS 오류를 겪고 프록시로 해결한 사례 ✅ [Canvas 커뮤니티](https://community.canvaslms.com/t5/Canvas-Developers-Group/CORS-Error-when-attempting-to-fetch-Calendar-Feed/m-p/618478). → Supabase **Edge Function** 하나가 대신 받아 줌. 로그인한 사용자만, **Canvas 도메인만** 허용(아무 주소나 받아 주는 '열린 프록시'가 되지 않게) |
| L3 | 피드 읽기 | iCal 해석은 직접 짜지 않고 **ical.js**(MPL-2.0) 사용 ✅ [저장소](https://www.github.com/kewisch/ical.js). 과목 이름을 일정 제목에서 어떻게 뽑을지는 실제 피드를 보고 정함 🔎 |
| L4 | 과목방·할 일 만들기 | 과목마다 개인방 1개(`ensureRoom`). 일정 1개 = 메모 1개, `due`·`dueTime` 채움. **일정 고유번호(UID)로 중복 방지**, 다시 받으면 마감 변경 반영 |
| L5 | 팀플 제안 | 키워드 감지 → 제안 카드 → 사용자가 누르면 공유방 생성(1바퀴 기능) |
| L6 | 다시 받기 | 앱 열 때 + 화면에 다시 들어올 때(최소 1시간 간격). Canvas 서버에 부담 안 주게 |

## 5. 이번엔 안 하는 것
- **강의 자료 파일 자동 정리**: 캘린더 피드로는 안 됨. Canvas API는 학교 관리자가 연결 키를 발급·승인해야 함 ✅ [Canvas OAuth 문서](https://developerdocs.instructure.com/services/canvas/oauth2/file.oauth) → **사업 계획의 '학교 제휴' 단계**로
- **과목 공지**: 학생용 공지 RSS가 있지만, 새 공지 화면(Announcements Redesign)을 쓰는 과목은 지원 안 됨 ✅ [Canvas 가이드](https://community.canvaslms.com/docs/DOC-1813) → 3바퀴 후보
- 푸시 알림(앱을 안 열어도 오는 알림), 다른 LMS(Moodle 등), To Do 항목
- 설문·팀 평가: 교수님이 **Canvas 일정이나 과제로 올렸을 때만** 들어옴. 카톡으로만 돈 설문은 못 가져옴 (붙여 넣으면 AI가 날짜 뽑기 — 기존 기능 활용 [판단])

|---|---|---|---|
| **Canvas Student 앱** (instructure/canvas-ios) | AGPL-3.0 ✅ [소개](https://awesome.ecosyste.ms/projects/github.com%2Finstructure%2Fcanvas-ios) | 과목·할 일·캘린더를 학생에게 어떻게 묶어 보여 주는지 | **구조·화면 흐름만** 참고, 코드 복사 금지 (AGPL) |

| 구글·애플 캘린더의 '주소로 구독' | – | 붙여 넣기 한 번으로 끝나는 연결 화면 | 화면 흐름 참고 |
| 경기대 '아차' 등 학교 알림 앱 | 비공개 | 연결 화면·알림 문구 | 팀원이 설치해서 캡처 (바깥에서 관찰만) |

## 7. 시험 (통과 기준)
| # | 시험 | 통과 기준 |
|---|---|---|
| V1 | 실제 피드 주소 붙여 넣기 | 과목 수만큼 방이 생기고, 각 방에 마감 할 일이 들어감 |
| V2 | 두 번 연결/다시 받기 | 방·할 일이 **중복으로 안 생김** |
| V3 | Canvas에서 마감 변경(또는 샘플 피드 수정) | 담다 할 일 마감이 바뀜 |
| V4 | 팀 과제 일정 | 제안 카드 → 누르면 공유방 + 코드 |
| V5 | 이상한 주소(Canvas 아님) | 서버가 거절, 앱은 안내 문구 |
| V6 | 로그인 안 한 상태 | 연결 불가 안내 |
| V7 | 피드 주소 노출 | 주소는 이 기기와 내 계정에만 저장, 서버 로그·다른 사람에게 안 보임 |

## 8. 위험과 대응
| 위험 | 대응 |
|---|---|
| **피드 주소 = 내 캘린더 열쇠** (주소만 있으면 누구나 내 일정을 봄 — Moodle 문서도 개인 인증값이 든 주소라 남에게 보이지 말라고 함 ✅ [Moodle 문서](https://docs.moodle.org/en/Calendar_export)) | 내 계정 전용 저장(RLS), 화면에 가려서 표시, 연결 끊기 버튼 |
| 우리 학교 Canvas에 '캘린더 피드' 버튼이 없을 수 있음 (학교가 끄거나, LearningX 화면이 다를 수 있음) 🔎 | **기획 확정 전에 실제 화면 확인** (아래 9번) |
| 일정 제목 형식이 과목마다 달라 과목 구분이 틀릴 수 있음 🔎 | 샘플로 확인 후 규칙 결정, 틀리면 사용자가 방 바꾸기 |
| Edge Function 무료 한도 | 무료 요금제에 호출 한도가 있음 🔎 (설계 단계에서 [요금 페이지](https://supabase.com/pricing)로 숫자 확인). 1시간에 1번만 다시 받게 해서 호출 수를 줄임 |

## 9. 설계 전에 필요한 것 (승호 님)
1. **우리 학교 Canvas 주소**(예: `canvas.○○.ac.kr`)
2. Canvas 캘린더 화면에 **"캘린더 피드(Calendar Feed)"** 버튼이 있는지 캡처
3. 있으면 **.ics 파일을 내려받아** 프로젝트 폴더에 두기 (주소 자체는 채팅에 붙이지 않기 — 열쇠라서). 이 파일로 과목·마감 형식을 확인하고, 커밋하지 않는다
