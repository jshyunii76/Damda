# 3바퀴 — 팀 회의실 (캐릭터로 모이는 2D 방)

> 작성: 2026-11-27 · 브랜치 `meet-v3` · 표기: ✅ 원문 확인 / 📁 코드 확인 / 🔎 확인 못 함 / [판단] 추정

## 목표
공유방(팀플방) 멤버가 **각자 꾸민 캐릭터**로 한 방에 모여, 걸어 다니며 말풍선·이모지·**가까이 가면 음성**으로 회의하고, 회의 출석을 방 기록으로 남긴다.

## 만든 것
| 항목 | 내용 |
|---|---|
| 입구 | 공유방 상단 '팀 회의실' 버튼 (공유방에서만) |
| 방 | 20×13칸. 테이블·의자·소파·책장·화분, 게시판에 이 방의 다가오는 마감 2개. 테마 4가지(사무실·카페·도서관·옥상) — 배치는 같고 모습만 다름, 내 화면에만 적용 |
| 캐릭터 | 색 8 + 꾸미기 6(없음·새싹·모자·안경·리본·헤드폰), 계정에 저장(`p:avatar`). 걸을 때 발·튀기, 눈 깜빡임, 표정(웃음·놀람·생각·손 흔들기), 말할 때 입 움직임 |
| 이동 | 방향키·WASD·바닥 누르기. 부딪힘 처리 |
| 대화 | 말풍선(60자), 이모지 5개 → 표정 |
| 음성 | 🎤 켜면 4칸 안의 음성 켠 팀원과 WebRTC 연결, 6칸 밖에서 끊음, 거리 따라 볼륨, 말하는 사람 발밑 초록 고리 |
| 기록 | '회의 출석 남기기' → 방에 `[회의] 날짜 시각 회의실 · 참석 N명: …` |
| 홈 | 내 캐릭터가 오늘 마감 수를 말풍선으로, 누르면 꾸미기 |
| 보안 | 채널 `meet:<방ID>` 은 private, `supabase/meet.sql` 정책으로 방 멤버만 듣고 보냄 |

## 시험
- SQL: 회의실 채널 정책 7개 (멤버 보내기·듣기 허용, 비멤버·없는 방·다른 이름 거절) — PGlite
- 가짜 서버 + 브라우저 2개(상현·우진): 서로 보임, 이동·말풍선·이모지·꾸미기 반영, 나가면 목록에서 빠짐, 출석 메모 서버 저장, 테마 4가지 그림 확인
- 음성: 가짜 마이크(발진기)로 두 탭 연결 `connected` · 상대 소리 수신 · 멀어지면 끊김 · 다시 오면 재연결 ✅
- 실제 Supabase(시험용): 멤버 채널 `SUBSCRIBED`, 비멤버 채널 `Unauthorized` ✅
