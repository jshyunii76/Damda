Damda 개인정보처리방침

시행일 2026년 11월 18일

Damda(이하 "앱")는 주제별로 메모를 모아 두는 앱입니다. 앱이 어떤 정보를 받고, 어디에 두고, 어떻게 지우는지 아래에 적습니다.

1. 받는 정보

  • 카카오로 로그인할 때: 닉네임, 프로필 사진(동의한 경우), 이메일(동의한 경우)
  • 구글로 로그인할 때: 이름, 이메일, 프로필 사진
  • 앱을 쓰면서 직접 만든 것: 방 이름, 메모, 첨부한 사진과 파일

위치, 연락처, 광고 식별자 같은 정보는 받지 않습니다.

2. 쓰는 곳

  • 로그인한 사람을 구별하고 화면에 이름을 보여 줍니다.
  • 메모를 서버에 저장해 같은 계정으로 로그인한 내 기기들끼리 맞춥니다.

광고에 쓰거나 다른 곳에 팔지 않습니다.

3. 저장하는 곳

로그인 정보와 메모·사진·파일은 Supabase 서버(서울 리전)에 저장됩니다. 서버에서는 본인 계정으로 로그인했을 때만 자기 기록을 읽고 쓸 수 있게 막아 두었습니다.

같은 내용은 쓰고 있는 기기 안에도 저장됩니다. 로그아웃하면 그 기기에 있던 기록, 사진, AI 키를 지웁니다.

4. 맡기는 곳

  • Supabase: 로그인 처리와 데이터 저장
  • 카카오, 구글: 로그인 확인
  • Google Gemini API: AI 정리 기능을 켠 경우에만, 정리할 메모와 사진을 기기에서 바로 보냅니다. 이때 쓰는 API 키는 사용자가 직접 넣으며 기기 안에만 저장되고 서버로 올라가지 않습니다.

5. 보관 기간과 삭제

메모와 파일은 사용자가 지울 때까지 보관합니다. 앱에서 지운 메모는 서버에서도 지워진 것으로 처리됩니다.
